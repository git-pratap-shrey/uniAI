# Attacks on Mobile Devices

**Subject**: CYBER_SECURITY | **Unit**: unit2

## Definition
Attacks on mobile devices are malicious actions designed to compromise device security, steal sensitive data, or disrupt network operations through various technical exploits.

## Key points
- **Push Attack**: Malicious actions initiated by external entities to exploit vulnerabilities (e.g., fake push notifications).
- **Pull Attack**: Device actively downloads malicious content from untrusted sources without user awareness.
- **Crash Attack**: Overloading a device or app to cause a system crash.
- **Phishing Variants**: Vishing (Voice), Smishing (SMS), and Mishing (Mobile Phishing) used to steal credentials.
- **Network Attacks**: DoS, Overbilling attacks, and signaling-level attacks on 3G/4G networks.
- **Bluetooth Hacking**: Unauthorized access to a device via Bluetooth to eavesdrop or control the device.

## Important terms
| Term | Meaning |
|------|---------|
| Vishing | Phishing conducted over a phone call. |
| Smishing | Phishing conducted via SMS/text message. |
| Overbilling | Manipulating network protocols to generate fraudulent charges. |

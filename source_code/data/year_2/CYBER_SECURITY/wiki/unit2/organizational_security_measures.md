# Organizational Security Measures

**Subject**: CYBER_SECURITY | **Unit**: unit2

## Definition
Organizational security measures are policies and technical strategies implemented to safeguard information systems and data within a mobile computing paradigm.

## Key points
- **Database Encryption**: Use algorithms like Rijndael or AES to protect sensitive data; keys should not be stored on the mobile device.
- **Mobile Device Management (MDM)**: Use tools to manage, monitor, and enforce security rules across all company devices.
- **Security Policies**: Define standards for configuration, app usage, and network connections.
- **Employee Training**: Educate staff on mobile risks, phishing, and safe browsing habits.
- **Asset Management**: Maintain an inventory of all mobile devices and revoke access upon employee departure.

## Important terms
| Term | Meaning |
|------|---------|
| MDM | Mobile Device Management; tools to manage mobile security. |
| Encryption | Encoding information so it cannot be understood without a key. |

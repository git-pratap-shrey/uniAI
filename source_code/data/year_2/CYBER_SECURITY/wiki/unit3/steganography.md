# Steganography

**Subject**: CYBER_SECURITY | **Unit**: unit3

## Definition
Steganography is the technique of hiding data within an ordinary, non-secret file or message to avoid detection.

## Key points
- Can hide text, images, video, or audio content.
- Often combined with encryption for extra security.
- Steganalysis: The technology used to detect and extract hidden data by analyzing bit patterns and file sizes.
- Tools: OpenStego, Steghide, OutGuess, QuickStego.
- Steganalysis Tools: StegDetect, StegExpose, StegSpy.

## Important terms
| Term | Meaning |
|------|---------|
| Steganalysis | The art of detecting and rendering meaningless covert messages. |
| Cover Text | The innocuous file used to hide secret data. |

# Viruses and Worms

**Subject**: CYBER_SECURITY | **Unit**: unit3

## Definition
A Virus is malicious code attached to an executable file that requires a host to spread; a Worm is malware that replicates itself and spreads through networks without a host.

## Key points
- Virus: Needs human action to replicate, more harmful, modifies/deletes data.
- Worm: Replicates automatically, consumes system resources (bandwidth/memory), can be controlled remotely.
- Virus types: Boot sector, Macro, Polymorphic, File infector.
- Prevention: Antivirus, firewalls, keeping OS/browsers updated, avoiding suspicious attachments.

## Important terms
| Term | Meaning |
|------|---------|
| Macro Virus | Virus embedded in documents like Word or Excel files. |
| Boot Sector Virus | Virus that infects the startup/boot process of a computer. |

## Exam questions likely on this topic
- Compare and contrast computer viruses and worms.
- What are the common symptoms of a virus infection?

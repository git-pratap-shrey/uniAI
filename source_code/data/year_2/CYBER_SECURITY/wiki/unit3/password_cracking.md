# Password Cracking

**Subject**: CYBER_SECURITY | **Unit**: unit3

## Definition
Password cracking is the process of uncovering passwords from data that have been stored in or transmitted by a computer system.

## Key points
- Online attacks: Direct interaction with the system (e.g., phishing, keylogging, dictionary attacks).
- Offline attacks: Attacker has access to hashed passwords; uses rainbow tables or brute-force.
- Tools: John the Ripper, Hashcat, Hydra, Medusa, RainbowCrack.
- Prevention: Use strong/unique passwords (12+ chars), MFA, password expiry, and secure hashing with salt.

## Important terms
| Term | Meaning |
|------|---------|
| Brute Force | Trying every possible combination until the correct password is found. |
| Rainbow Table | Precomputed table of hashes used to reverse password hashes. |

## Exam questions likely on this topic
- Explain the difference between online and offline password cracking.
- List and explain common password cracking tools.

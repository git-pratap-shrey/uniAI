# DoS and DDoS Attacks

**Subject**: CYBER_SECURITY | **Unit**: unit3

## Definition
Denial-of-Service (DoS) is an attack meant to shut down a machine or network by flooding it with traffic or triggering a crash; DDoS uses multiple compromised devices (botnets).

## Key points
- Attack types: Volumetric (UDP/ICMP floods), Protocol (SYN floods), Application Layer (HTTP floods).
- DDoS: Uses botnets (e.g., Mirai, XOR DDoS) to coordinate attacks.
- Tools: LOIC, HOIC, Xerxes, GoldenEye, Hping, Memcrashed.
- Mitigation: Traffic monitoring, anomaly detection, rate limiting, scalable infrastructure, firewalls.

## Important terms
| Term | Meaning |
|------|---------|
| Botnet | A network of compromised devices used to launch DDoS attacks. |
| SYN Flood | A protocol attack exploiting the TCP handshake process. |

## Exam questions likely on this topic
- Differentiate between DoS and DDoS attacks.
- List and explain the methods used to mitigate DoS/DDoS attacks.

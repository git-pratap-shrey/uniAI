# Trojan Horse and Backdoors

**Subject**: CYBER_SECURITY | **Unit**: unit3

## Definition
A Trojan Horse is malware disguised as a legitimate program; a Backdoor is a hidden method of bypassing authentication in a system.

## Key points
- Trojans: Erase/corrupt data, log keystrokes, allow remote access, disable security software.
- Backdoors: Can be intentional (for maintenance) or malicious (for unauthorized access).
- Examples: Netbus, SubSeven, Back Orifice, DarkComet, Poison Ivy.
- Protection: Antivirus, keep software updated, firewall, strong authentication, regular backups.

## Important terms
| Term | Meaning |
|------|---------|
| Trojan Horse | Malware disguised as normal software to trick users into installing it. |
| Backdoor | A hidden, undocumented way to bypass normal authentication. |

## Exam questions likely on this topic
- What is a Trojan Horse? List its threats.
- Explain the purpose of backdoors and how to protect against them.

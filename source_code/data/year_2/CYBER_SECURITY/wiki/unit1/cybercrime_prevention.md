# Cybercrime Prevention

**Subject**: CYBER_SECURITY | **Unit**: unit1

## Definition
Cybercrime prevention involves the implementation of security measures and best practices to protect systems, data, and users from digital threats.

## Key points
- **Netizen Mantra (5Ps)**: Precaution, Protection, Prevention, Preservation, Perseverance.
- **General Measures**: Use strong, unique passwords; keep software updated; use trusted antivirus; avoid public Wi-Fi.
- **Cybercafe Safety**: Always logout, clear history/temporary files, avoid financial transactions on public computers, and be alert to shoulder surfing.
- **Data Security**: Use encryption and perform regular backups.

## Important terms
| Term | Meaning |
|------|---------|
| Malware | Malicious software designed to damage or gain unauthorized access. |
| Firewall | A security system that monitors and controls network traffic. |
| Virtual Keyboard | An on-screen keyboard used to prevent keylogging during sensitive transactions. |

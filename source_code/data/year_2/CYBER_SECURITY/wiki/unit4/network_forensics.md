# Network Forensics

**Subject**: CYBER_SECURITY | **Unit**: unit4

## Definition
Network forensics is a sub-branch of digital forensics that involves monitoring, capturing, and analyzing network traffic to detect security incidents and investigate cyber attacks.

## Key points
- Goal: To understand and account for malicious activities occurring across a network.
- Process: Identification, Safeguarding, Accumulation (reporting/duplication), Observation, Investigation, and Documentation.
- Challenges: High-speed data transmission, data privacy, access to IP addresses, and data integrity.
- Advantages: Identifies threats/vulnerabilities, monitors performance, and reduces downtime.

## Important terms
| Term | Meaning |
|------|---------|
| Network Traffic | Data packets moving across a network. |
| Network Forensics | Detective work for computer networks. |
